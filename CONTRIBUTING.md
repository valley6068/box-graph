# Helping with Box Graph

Thanks for wanting to help!

## Found a bug?

[Open an issue](../../issues/new/choose) and pick **Something is broken**. Tell me what you did and what went wrong. A screenshot is the best thing you can add. I read every one.

## Have an idea?

Open an issue and pick **Idea**. Tell me what you're trying to do. That helps more than a finished solution.

## Want to change the code?

Box Graph is one plain JavaScript file, `main.js`, with no build step and no libraries. To try a change, copy `main.js` and `manifest.json` into `<your vault>/.obsidian/plugins/box-graph/`, then turn the plugin off and on in Obsidian.

If you send a pull request, keep it small and about one thing. And please keep it fast: Box Graph should never read every note's text at once.
